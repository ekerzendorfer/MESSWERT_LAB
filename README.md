# MESSWERT_LAB v0.4.0

Browserbasierte schulische Messwertauswertung als Single-HTML-App.

## Module

- Eichkurve und unbekannte Probe
- Photometrische Kinetik (Kristallviolett, Brillantblau, Iod-/Vitamin-C-Uhr)
- Bromthymolblau-pH-Serie: Spektren, Zusammensetzung und pKa

## Start

`index.html` lokal öffnen oder auf GitHub Pages bereitstellen. Alle Berechnungen erfolgen lokal im Browser.
